帧配装机 · 价格数据接入说明

把 DIY 价格追踪的数据接到小程序里 · 2026-10-04
结论：不用域名、不用备案，今天就能连上。
微信官方文档写明：小程序「网络接口只允许与同个局域网内的非本机 IP以及配置过的服务器域名通信」 （基础库 2.4.0 起支持局域网 IP）。所以只要手机和电脑连同一个 WiFi， 小程序就能直接请求电脑上的服务。出门在外（不同网络）才需要公网的 HTTPS + 备案域名。

一、先确认数据是通的（1 分钟）

  1. 手机上连上和电脑同一个 WiFi。
  2. 手机浏览器打开： 
    http://192.168.1.18:8848/build
  3. 能看到「我的主机 ¥9,184」这张卡片，就说明数据链路已经通了 —— 剩下只是把请求搬进小程序。
IP 可能变。电脑的局域网 IP 由路由器分配，重连 WiFi 或重启路由器后可能变化。 在电脑上执行 ipconfig getifaddr en0 可以查到当前的；如果长期用，建议在路由器里给它绑定固定 IP。

二、接口清单

所有接口都在 http://<电脑IP>:8848 下，请求和响应都是 JSON（UTF-8）。

方法路径用途请求体
GET /api/builds 所有配置单 + 实时总价 —
POST /api/builds 新建配置单 {"name":"我的主机","note":""}
POST /api/builds/{id} 改名 / 改备注 {"name":"…","note":"…"}
DELETE /api/builds/{id} 删除整套配置 —
POST /api/builds/{id}/items 往配置里加配件 {"product_id":101,"quantity":1}
POST /api/build-items/{itemId} 改数量 / 改备注 {"quantity":2}
DELETE /api/build-items/{itemId} 移除一个配件 —
GET /api/products?q=5060&limit=20 搜型号（加配件时用） —
⚠️ 改数据请用 POST，不要用 PATCH。 小程序的 wx.request 的 method 只支持 OPTIONS / GET / HEAD / POST / PUT / DELETE / TRACE / CONNECT，没有 PATCH。 服务端已经把「改」类接口同时挂上了 POST，两个都能用 —— 网页端走 PATCH，小程序走 POST。

三个字段必须理解，否则会显示错价格

字段含义怎么用
price 稳健价（当天报价的 25 分位） 算总价、显示"大概多少钱"用它
low 当天真实最低挂牌价 想提示"还有人挂得更低"时用它，但不要计入总价
date 这个价是哪天的 务必显示出来（京东每轮只采 2 个型号，进度可能落后好几天）

为什么不能用 low 算总价：实测 RTX 5060 Ti 16G 在闲鱼的最低价是 ¥2300， 而当天真实行情约 ¥4400 —— 那条标题是「技嘉 RX6800 超级雕…换了 5060Ti 故出」， 卖的其实是 RX 6800，只因句子里提到"5060Ti"就被归到了这个型号名下。 用最低价算总价，整套配置会凭空便宜两千块。

四、小程序端怎么调

1）封装一个请求方法（utils/api.js）

const BASE = 'http://192.168.1.18:8848';   // ← 换成你电脑当前的局域网 IP

function req(path, method, data) {
  return new Promise((resolve, reject) => {
    wx.request({
      url: BASE + path,
      method: method || 'GET',            // ⚠️ 没有 PATCH，改数据用 POST
      data: data || undefined,
      header: { 'Content-Type': 'application/json' },
      success: (res) => {
        if (res.statusCode >= 200 && res.statusCode < 300) resolve(res.data);
        else reject(new Error((res.data && res.data.detail) || ('HTTP ' + res.statusCode)));
      },
      fail: reject,
    });
  });
}

module.exports = {
  listBuilds:   ()            => req('/api/builds'),
  createBuild:  (name)        => req('/api/builds', 'POST', { name: name }),
  renameBuild:  (id, name)    => req('/api/builds/' + id, 'POST', { name: name }),
  deleteBuild:  (id)          => req('/api/builds/' + id, 'DELETE'),
  addItem:      (id, pid)     => req('/api/builds/' + id + '/items', 'POST', { product_id: pid }),
  setQuantity:  (itemId, q)   => req('/api/build-items/' + itemId, 'POST', { quantity: q }),
  removeItem:   (itemId)      => req('/api/build-items/' + itemId, 'DELETE'),
  searchModels: (kw)          => req('/api/products?limit=20&q=' + encodeURIComponent(kw)),
};

2）页面里用（示例）

const api = require('../../utils/api.js');

Page({
  data: { builds: [], keyword: '', hits: [] },

  onShow() { this.loadBuilds(); },

  loadBuilds() {
    api.listBuilds()
      .then((d) => this.setData({ builds: d.items }))
      .catch((e) => wx.showToast({ title: '加载失败', icon: 'none' }));
  },

  onSearch(e) {
    const kw = e.detail.value.trim();
    if (!kw) return this.setData({ hits: [] });
    api.searchModels(kw).then((d) => this.setData({ hits: d.items }));
  },

  onAdd(e) {
    const { buildId, productId } = e.currentTarget.dataset;
    api.addItem(buildId, productId)
      .then((updated) => {
        // 接口直接返回更新后的这一套配置，可以原地替换
        const builds = this.data.builds.map((b) => (b.id === updated.id ? updated : b));
        this.setData({ builds: builds, hits: [] });
      });
  },
});

五、注意事项

  • 手机和电脑必须在同一个 WiFi。这是零成本方案的前提。
  • 电脑不能休眠。合盖或睡眠后服务就断了（这也是现在只做自用的原因之一）。
  • 开发者工具报「不在以下 request 合法域名列表中」时：右上角「详情」→「本地设置」→ 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。 真机调试同样需要打开调试模式。
  • 出门在外用不了。不同网络下必须走公网 HTTPS + 已备案域名（微信硬性要求，域名还必须 ICP 备案）。 真要做到那一步，优先考虑把服务放到微信云托管（平台给 HTTPS 域名，不用自己备案）， 而不是自己去买域名走备案流程。
  • 接口没有任何鉴权 —— 所以只在受信任的家庭/办公局域网里开， 不要把电脑的 8848 端口直接映射到公网。
